## 📝 Sobre o Projeto
Este projeto foi desenvolvido para explorar o design de interfaces de streaming (UI/UX). Diferente do catálogo padrão, este modelo reflete meus gostos pessoais e conta com ajustes específicos na estrutura e na experiência do usuário.

### ✨ Diferenciais:
- **Curadoria Pessoal:** Filmes e séries selecionados com base nas minhas preferências.
- **Desenvolvimento Auxiliado por IA:** Utilizei ferramentas de Inteligência Artificial para otimizar o código, sugerir melhorias na lógica e refinar o design.
- **Interface Adaptável:** Foco em manter a fluidez visual da Netflix original com toques de personalização.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** HTML5, CSS3 (ou React/Next.js se aplicável)
- **Design:** CSS Grid & Flexbox
- **IA:** O copilot (IA da Microsoft) para auxílio técnico.
